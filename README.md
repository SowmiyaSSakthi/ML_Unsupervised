# Customer Segmentation Using Clustering

## 📌 Project Overview

This project applies **Unsupervised Machine Learning** techniques to perform customer segmentation using the Mall Customers dataset.

The goal is to group customers based on their **Annual Income** and **Spending Score** to identify different customer segments.

## 🎯 Objectives

- Understand customer segmentation using clustering algorithms.
- Apply K-Means Clustering.
- Use the Elbow Method to help determine the optimal number of clusters.
- Apply Hierarchical Clustering.
- Visualize customer groups and understand their spending patterns.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy
- Jupyter Notebook / Google Colab

## 📂 Dataset

**Dataset:** Mall Customers

The dataset contains customer information, including:

- Customer ID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1–100)

For clustering, this project uses **Annual Income** and **Spending Score**.

## 🤖 Machine Learning Algorithms

### 1. K-Means Clustering

K-Means groups customers into clusters based on similarities in their selected features.

**Steps performed:**
- Load the dataset.
- Select Annual Income and Spending Score.
- Use the Elbow Method to examine the suitable number of clusters.
- Apply K-Means with 5 clusters.
- Visualize the resulting customer groups.

### 2. Hierarchical Clustering

Hierarchical Clustering groups customers based on their similarity and hierarchical relationships.

**Steps performed:**
- Load and prepare the dataset.
- Select Annual Income and Spending Score.
- Create a dendrogram using Ward's linkage method.
- Apply Agglomerative Clustering with 5 clusters.
- Visualize the resulting clusters.
